About 45 seconds. This is how the deployment on the previous slide gets built, taken directly from our written deployment plan; none of it is started yet. Steps one to three are code: first, jobs are sent to Modal instead of Redis and Celery, with a Modal timer that restarts lost jobs; second, the file locks that stop a dataset being deleted mid-training move into MongoDB, and that part gets a separate code review because it is the riskiest; third, we package the API and training for Modal with one shared storage volume, and the dashboard for Vercel, which forwards API calls to Modal. Step four is ours: create the Atlas, Modal and Vercel accounts. Step five is two deploy commands, with every key kept in Modal’s secret store. Step six proves it on the public link end to end, including Claude chat, and records start-up time and cost. The local Docker and Kubernetes setup the course requires stays as it is.
