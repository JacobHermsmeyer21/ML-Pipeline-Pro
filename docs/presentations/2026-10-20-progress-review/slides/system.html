About 1 minute 15 seconds. Read the tree top-down. The root is the shared platform: FastAPI services backed by MongoDB for records and Redis as the job queue. It splits into four parts, and each runs as its own service, which is a course requirement. Data lives in the model service; training runs on a serial CPU worker plus a separate tuning service; monitoring is its own service feeding Grafana; and the assistant runs on Claude through the Anthropic API; it can only use typed tools and must get approval before anything runs.
